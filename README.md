# Чекпоинт 1: агент поддержки интернет-магазина

Агент находит заказ, отменяет его, меняет адрес доставки и оформляет возврат. Правила магазина проверяет код инструментов, модель только выбирает действие и объясняет результат клиенту.

## Устройство

| Часть | Где |
|---|---|
| Инструменты с правилами | `src/tools/order_tools.py` (`OrderTools`), схемы аргументов `src/schemas/tool_args.py`, описания для модели `src/tools/definitions.py` (`strict: true`) |
| Системный промпт | `src/prompts/system.py`: роль, правила ответа по документам, дата «сегодня» из `data/orders.json` |
| Цикл агента | `src/services/chat.py`: Responses API без фреймворков, не больше 8 шагов на ход (`MAX_STEP`) |
| Сервис | FastAPI, ответ стримится по SSE, история сессии хранится в SQLite (`support.db`, таблица `messages`) и переживает перезапуск |

## Запуск

В `.env` нужны `OPENAI_API_KEY` и цены модели (см. «Цена диалога»).

```bash
poetry install
poetry run uvicorn src.app:app --env-file .env
```

| Метод | Путь | Тело |
|---|---|---|
| POST | `/users` | `{"title": "Имя"}` → `id` пользователя |
| POST | `/sessions` | `{"user_id": 1}` → `id` сессии |
| GET | `/sessions/{id}` | история сессии |
| POST | `/sessions/{id}/messages` | `{"text": "..."}` → SSE: `text`, `usage`, `done` или `error` |

## Проверки

```bash
poetry run pytest checks/test_cancel_order.py
poetry run pytest checks/test_history.py --db support.db
```

`test_history.py` читает реальную базу: перед ним нужно провести диалог с отменой заказа и перезапустить сервер посередине. Адаптер `checks/adapter.py` отдаёт тестам `ORDERS`, `REFUNDS`, `reset_state`, `run_tool`, `TOOL_IMPL` и `TOOLS` поверх класса `OrderTools`.

## Цена диалога

Токены берутся из `usage` каждого ответа модели и складываются по всем шагам хода. После ответа сервис отдаёт событие `usage`:

```
event: usage
data: {"steps": 2, "input": ..., "cached": ..., "cache_write": ..., "output": ..., "reasoning": ..., "cost_usd": ...}
```

Стоимость считается как в уроке 00:

```
cost = ((input − cached − cache_write) × PRICE_INPUT
        + cached × PRICE_CACHED
        + cache_write × PRICE_CACHE_WRITE
        + output × PRICE_OUTPUT) / 1 000 000
```

Цены за 1M токенов задаются в `.env`, а не в коде. Для `gpt-5.6-luna` (прайс курса, сентябрь 2026): вход $0.20, вход из кэша $0.02, запись в кэш $0.25, выход $1.20.

## Effort

Выбран `reasoning.effort = "low"`.

- Задачи агента короткие: найти заказ, вызвать один инструмент, пересказать результат. Длинных рассуждений они не требуют.
- Правила магазина проверяет код. Если модель выберет неверное действие, инструмент вернёт ошибку с подсказкой, и модель исправится на следующем шаге. Поэтому дополнительные рассуждения почти не повышают правильность.
- Reasoning-токены оплачиваются как выход, а выход в 6 раз дороже входа. Более высокий effort увеличивает цену и время до первого токена, а клиент ждёт ответа в чате.
